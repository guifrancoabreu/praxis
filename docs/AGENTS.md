# Documentation (`docs`) — agent reference

@../AGENTS.md

## Placement

Cross-cutting docs — both platforms, or the project as a whole — go in `docs/*.md`. A single area's material goes in its `docs/<area>/` folder: `design/` for the visual language both apps follow, `stores/` for App Store and Play submission material.

`docs/` holds maintained documentation. Plans, agent handoffs and session notes do not live in this repo at all — no folder for them, ignored or otherwise. A plan belongs in the issue or PR that ships it.

This folder is also the GitHub Pages root, so anything added here is publicly readable as a raw file.
